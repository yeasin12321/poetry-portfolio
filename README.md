# 📖 Poetry Portfolio

একটি আধুনিক ও মিনিমালিস্ট ওয়েব পোর্টফোলিও, যেখানে বাংলা কবিতা, ব্যক্তিগত সাহিত্য সৃষ্টি এবং সুরের মেলবন্ধন তুলে ধরা হয়েছে। 

---

## ✨ বৈশিষ্ট্যসমূহ (Features)

- **ক্লিন ইউজার ইন্টারফেস:** কবিতা পড়ার জন্য আরামদায়ক ও আধুনিক টাইপোগ্রাফি।
- **ব্যাকগ্রাউন্ড মিউজিক:** পড়ার অভিজ্ঞতাকে আরও গভীর করতে ব্যাকগ্রাউন্ড অডিও প্লেয়ার সাপোর্ট।
- **রেসপনসিভ ডিজাইন:** মোবাইল, ট্যাবলেট এবং ডেস্কটপ সব ডিভাইসেই সহজে ব্যবহারযোগ্য।
- **এসইও ফ্রেন্ডলি:** প্রোপার সার্চ ইঞ্জিন অপ্টিমাইজেশনের জন্য `sitemap.xml` এবং `robots.txt` কনফিগার করা।

---

## 📁 ফাইল স্ট্রাকচার (File Structure)

```text
├── eye.jpg          # ব্যানার / কনসেপ্ট ইমেজ
├── favicon.png      # ব্রাউজার ট্যাব আইকন
├── index.html       # ওয়েবসাইটের মূল স্ট্রাকচার ও কনটেন্ট
├── music.mp3        # ব্যাকগ্রাউন্ড অডিও ট্র্যাক
├── profile.jpg      # প্রোফাইল ছবি
├── robots.txt       # সার্চ ইঞ্জিন রোবট কনফিগারেশন
├── rumi.mp3         # বিশেষ অডিও / কবিতার আবৃত্তি
├── script.js        # ইন্টারেক্টিভ লজিক ও অডিও কন্ট্রোলার
├── sitemap.xml      # এসইও সাইটম্যাপ
└── style.css        # কাস্টম স্টাইলিং ও লেআউট
